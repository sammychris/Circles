# Start something

**Kind:** 3-step flow · **Release:** V1 (Talk only); Learn and Play choices appear with their phases
**Entry:** the "Start one" link on each door page (with that door chosen), My people › Start a room with friends, search empty state. Replaces "Start a topic room" and "New circle".

## Step 1: What would you like to start?
Radio cards (88 tall): **Talk** (A room about a topic or idea), **Learn** (Practise a language or skill together), **Play** (A game or watch-along while you talk). If only Talk exists, skip this step.

## Step 2: Once or every week?
- **Just once:** now, or at a set time today or later this week.
- **Every week:** day(s) and time. This creates a group; each meeting opens a room.

## Step 3: Details (depends on the kind)
| Kind | Fields |
|---|---|
| Talk | Topic tag, title (40 chars), size (Small, up to 6; Hosted, up to 10, needs host status for mood rooms), who can join (anyone, invite only) |
| Learn | Language or skill, level (Beginner, Getting there, Fluent), title, size (up to 7 free). Verified hosts also see **Paid class** (up to 12) and the Set a price step (`paid-groups.md`) |
| Play | Game, game night (everyone plays on their own device) or watch-along; title; size (2 to 6) |

All kinds: optional description (280 chars), rules reminder, then **Start** (now) or **Create group** (every week). Toast after: "Night Owls is set for Fridays at 10 pm. We'll remind you."

## Rules
- Kinds that need a trained or verified host are visible but disabled for others, with "Needs a verified host. Apply in Me › Host tools."
- One flow, one look; new kinds add a radio card and a details table row, nothing else.
