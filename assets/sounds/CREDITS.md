# Game sounds

Made for Circles by `scripts/make-sounds.py`, from plain tones and noise. Nothing was copied from a sound pack, so there is no licence to follow. Run the script again to remake them.

| File | Moment |
|---|---|
| `turn.wav` | Your turn (a soft two-note chime, only on your phone) |
| `dice.wav` | Dice roll |
| `move.wav` | A piece moves |
| `capture.wav` | Capture |
| `card.wav` | A card is played |
| `market.wav` | Going to market |
| `night.wav` / `day.wav` | Mafia: night falls / day breaks |
| `won.wav` | Game won |
